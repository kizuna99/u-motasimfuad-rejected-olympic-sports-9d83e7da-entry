# Rejected Olympic Sports — entry

A tiny Python program that writes one funny single-line sport the Olympics
turned down to `/output/entry.txt`, exactly as the bounty contract requires
(UTF-8, 1–200 characters, nothing else).

The line:

> Competitive Apologising was rejected after Canada swept the podium, then apologised for sweeping the podium.

It was picked in an in-session tournament of ten candidates against the
judge's published criteria: a made-up event plausible enough to read aloud
on a broadcast, no wasted words, and a twist quotable enough to repeat —
the champions apologising for winning is the whole joke, and it lands in
one breath.
